# nexo

Instaladores de **nexo**, una terminal para Windows pensada para trabajar con Claude Code y Codex en varios proyectos.

## Instalar

1. Entra a [Releases](https://github.com/CarlosACQ/nexo-releases/releases/latest) y baja `nexo_<versión>_x64-setup.exe`.
2. Ábrelo. Windows puede mostrar "Windows protegió tu PC": elige "Más información" y "Ejecutar de todas formas".
3. Se instala en tu usuario, sin pedir administrador.

## Actualizaciones

nexo avisa cuando hay una versión nueva y tú eliges cuándo actualizar. Cada versión va firmada: nexo solo instala lo que viene de acá.

Este repositorio solo tiene los instaladores; el código es privado.
